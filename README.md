# 📊 Dataset - Data Visualization Project

This project focuses on **Data Visualization** of the **Dataset**, turning raw data into clear, insightful visuals. The goal is to reveal business trends, customer behavior, and sales performance in an engaging and informative way.

## 📁 Project Structure

- **Datavisualization.ipynb** — Jupyter Notebook containing all visualizations based on the 2019 Superstore dataset.

## 📂 Dataset

- **2019.csv** — Contains detailed records of sales, customers, shipping, discounts, and profits for the year 2019.

## 🌟 Project Highlights

- 📈 Sales performance visualizations over time
- 🌍 Regional and category-wise sales breakdown
- 🧩 Customer segmentation and spending analysis
- 🎯 Impact of discounts on profitability
- 🔥 Correlation heatmap to understand key relationships
- 🛳️ Shipping mode distribution analysis
- 🎨 Clean and engaging charts using Matplotlib and Seaborn

## 🛠️ Tools & Libraries

- Python
- Pandas
- Matplotlib
- Seaborn

## 🚀 How to Run

1. Download or clone this repository.
2. Make sure the **2019.csv** file is in the same directory as the notebook.
3. Install required libraries:
